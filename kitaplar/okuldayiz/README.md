# A1, 2. Ünite: Okuldayız

PDF Modu; özgün PDF sayfalarını, tek dil seçmeli yerel sözlüğü, kelime/ifade seçimini, örnekleri ve cevapları gösterir. Beş hedef dil İngilizce, Rusça, Kırgızca, Arapça ve Fransızcadır. Çeviriler yerel içerik dosyasındadır; Google Translate isteği yapılmaz.

Kitap 20 sayfadır. Kaynak ses kodları sayfalarda bulunur; ilgili ses dosyaları kullanıcıdan gelince `audio/` altına eklenip düğmelere bağlanacaktır.
