# A1 • 10. Ünite — Tatil Planım

28 original textbook pages with coordinate-based word buttons, longest-match phrase selection (including line-wrapped words), five-language dictionary cards, lemma and textbook-form meanings, daily examples, local vocabulary notebook, and 20-question vocabulary/listening/writing practice.

Dictionary language order: Turkish, English, Russian, Kyrgyz, Arabic. The unit is based on the uploaded textbook, including its historical dates and figures.

Pronunciation uses the existing shared speech archive and an exact-language device voice. The shared archive does not cover every new expression. When neither a recording nor the correct device voice exists, the UI explicitly reports that the audio is unavailable; it never substitutes another language. Original S.119–S.131/M.019–M.020 listening recordings have not been supplied and are not included.

Browser interaction and complete audio playback have not been verified in this environment. Data coverage, phrase matching, image generation and JavaScript syntax are checked locally. Translation case forms were prepared and reviewed for common vocabulary; further native-language editorial review is advisable for the full inflected inventory.
