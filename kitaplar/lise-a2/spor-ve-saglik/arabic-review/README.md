# A2 unit 8 Arabic voice review

Eight comparisons (four vocabulary items and four sentences), with old audio segments and new Piper ar_JO-kareem-medium recordings. This folder is a review only: live speech/index.json is unchanged. New speech uses reviewed diacritics, length_scale=1.08, noise_scale=0.55, noise_w_scale=0.7, 22,050 Hz mono MP3 at 96 kb/s. Loudness normalized with ffmpeg loudnorm I=-18, TP=-1.5, LRA=9. Semicolon text is retained in full. Technical audio checks are not a native-speaker pronunciation review.

Voice: https://huggingface.co/rhasspy/piper-voices/tree/main/ar/ar_JO/kareem/medium
Dataset: https://github.com/AliMokhammad/arabicttstrain/
Piper: https://github.com/OHF-Voice/piper1-gpl
No model weights are distributed here.
