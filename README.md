# turkce-akademi
Türkçe Akademi – Dünyanın Türkçe Öğrenme Platformu. A1-C1 seviyelerinde ücretsiz Türkçe dersleri, kelime oyunları, dil bilgisi, dinleme etkinlikleri ve online sınavlar.


## Etkileşimli A1 kitabı
İlk ünite **Tanışalım** sayfalarını açın: [Etkileşimli kitabı başlat](kitaplar/tanisalim/). Kelimelere dokunarak İngilizce, Rusça, Kırgızca, Arapça ve Fransızca karşılıklarını görün.
